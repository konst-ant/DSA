# Modern FAANG-Style Interview Task Catalog

A standalone, general-purpose list of 100 canonical problems representative of modern FAANG/big-tech live coding interview loops (the "Blind 75 / NeetCode 150" style canon). Grouped by pattern; patterns themselves are ordered roughly by how frequently they come up across live loops, and problems within each pattern are ordered the same way. Not tied to any class in this repository.


## Hint: Before submitting your solution at coding interview do:
My 30-second algorithm verification checklist
Before submitting your solution0/7


[ ] Have I handled nulls, empty inputs and boundary conditions?
[ ] Do all index increments correspond to the correct operation?
[ ] Are my loop conditions and termination conditions correct?
[ ] Are array/list boundaries correct (especially exclusive end indices)?
[ ] Have I checked what happens when one input is exhausted before another?
[ ] Can I manually trace at least one non-trivial example?
[ ] Does the implementation preserve its key invariants?

Resist the to write code quickly because you feel you should already know these patterns.

I'd rather see you spend:
- 60% of your effort understanding the algorithm.
- 25% implementing it carefully.
- 15% verifying it.
